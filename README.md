# Soft Place

눈사람 친구를 하나 만들고, 모닥불과 별, 빗소리, 파도, 도서관, 온천 사이를 천천히 걸어 다니는 3D 힐링 웹사이트예요.

## 지금 있는 것

- 공간 9곳: 중앙 광장, 모닥불 캠핑장, 딸깍 정원, 비 오는 숲, 파도 해변, 수다 마당, 눈 속 도서관, 눈꽃 온천, 풍경 나무
- 눈사람 꾸미기 (이름, 옷 색, 액세서리)
- 앉기, 불멍, 누워서 별 보기, 책 읽기, 온천 들어가기, 절벽 끝 벤치에서 전망 보기
- 광장에서 나가는 길마다 방향 표지판
- 캠핑장: 은하수와 별이 가득한 밤하늘, 북쪽 절벽 너머 겹겹이 산과 먼 마을 불빛, 안에 랜턴이 켜진 큰 돔 텐트, 사진 텍스처 흙·돌바닥·나무껍질
- 불멍 중 마시멜로 굽기 (Q): 하양 → 노릇 → 갈색 → 숯까지 얼룩덜룩 구워지고, 먹기 전에 눈앞에서 보여줘요. 익은 정도마다 먹는 소리가 달라요 (쫀득 / 바삭 / 탔으면 숯 부서지는 소리 + 콜록 기침과 검은 재 연기). 불이 붙으면 '후~' 불어서 꺼요
- 원소 6가지(리튬·칼슘·나트륨·바륨·구리·칼륨): 솜 손이 염화물 가루를 불에 뿌리면 불이 '휙' 커졌다가 돌아오면서 불꽃 색이 바뀌어요
- 아주 가끔 유성우: 12분마다 한 번 기회(70%)라서 모두에게 같은 시간에 내려요. 주소 끝에 `#meteors`를 붙이면 바로 볼 수 있어요
- 소리는 파일 없이 브라우저가 직접 만들어요. 모닥불은 불빛처럼 일렁이고, 타닥 소리는 몰아서 났다가 쉬어요
- 조작: WASD·방향키로 걷고, 마우스로 끌어서 둘러봐요 (앉은 자리에서도 고개를 돌릴 수 있어요). 마우스 클릭으로는 걷지 않아요. 폰은 바닥을 톡 누르면 걸어요
- 공중샷 (V): 하늘에서 내려다봐요. 휠로 높이를 바꿔요

- 눈밭을 걸으면 동글동글 발자국이 남고 3분쯤 지나면 사라져요 (발자국으로 그림을 그리고 공중샷으로 볼 수 있어요). 가까운 눈은 반짝반짝
- 처음에 들어가는 방법을 골라요: 혼자 있기 / 아무 방이나(랜덤, 한 방 12명까지) / 방 만들기(코드 4글자를 친구에게) / 코드로 들어가기. 꾸미기 → 방 바꾸기에서 언제든 바꿀 수 있어요
- 같이 있기: 같은 방 사람의 눈사람, 이름, 움직임, 발자국이 보이고 숫자 1~5로 이모티콘을 보낼 수 있어요

## 같이 있기 켜는 법

`index.html` 맨 위쪽 `const FIREBASE_DB_URL = "";` 따옴표 안에 Firebase Realtime Database 주소를 넣으면 다른 사람과 연결돼요.
비워 두면 **탭 시험 모드**예요. 같은 브라우저에서 탭을 두 개 열고 같은 방에 들어가면 서로 보여요 (다른 컴퓨터끼리는 안 만나요).

방은 데이터베이스에 `pub/방코드`(랜덤 방, 목록을 읽을 수 있음)와 `prv/방코드`(코드 방, 코드를 아는 사람만 읽음)로 나뉘어 저장돼요.

데이터베이스 규칙은 `database.rules.json`에 있어요. Firebase 콘솔의 Realtime Database → 규칙 탭에 그대로 붙여 넣고 게시하면 돼요.
지금 규칙은 로그인 없이 누구나 쓸 수 있는 시험용이라, 크게 공개하기 전에 익명 로그인을 붙여야 해요.

## 파일

- `index.html` 하나에 전부 들어 있어요. 브라우저로 열면 바로 돌아가요.
- `database.rules.json`: 같이 있기용 Firebase 데이터베이스 규칙
- `textures/`: 사진 텍스처. 없으면 그림 텍스처로 대신 그려요.
- `AGENTS.md`: AI 작업자용 인수인계 문서 (코드 지도, 규칙, 정해진 것, 지금 상태)
- `PLAN.md`: AI 작업자 둘(Claude, Codex)의 협업 계획
- 3D는 three.js r128 (cdnjs)을 써요.

## 고마운 곳

사진 텍스처는 [Poly Haven](https://polyhaven.com)에서 받았어요 (CC0, 누구나 자유롭게 사용): Forest Ground 06, Rocks Ground 06, Bark Brown 01. 눈은 일부러 사진 대신 뽀송한 그림 눈으로 그려요. 웹에서 빨리 뜨게 1K 사진을 줄이고, 울퉁불퉁 정보(normal map)는 EXR에서 JPG로 바꿨어요.
