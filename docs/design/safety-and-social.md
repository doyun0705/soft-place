# C6 같이 있기의 안전과 조작 (설계안)

Claude가 쓴 설계안이에요. `PLAN.md` 7번 방식대로 Codex가 문제점을 3개 이상 찾고, 도윤이 골라요. 고른 내용은 `AGENTS.md` 7번에 적어요. 게임 코드는 바꾸지 않았어요.

K4(#7, 익명 인증·자기 세션만 쓰기·도배 막기)가 "누가 무엇을 쓸 수 있나"를 정한다면, 이 문서는 "사람끼리 만났을 때 기분 나쁜 일을 어떻게 줄이나"와 "어떻게 움직이고 둘러보나"를 정해요.

## 지금 상태 (2026-11-22)

- 로그인 없이 닉네임(최대 12글자)만 써요. 이름을 거르는 장치는 없어요.
- 글자 채팅은 없고, 정해진 이모티콘만 보낼 수 있어요. 이게 지금 가장 큰 안전장치예요.
- 차단, 신고, 음성 대화는 없어요. 음성은 수다 마당에서만 켤 예정이라고 정해 뒀어요.
- 폰은 바닥을 톡 눌러 걷고, 조이스틱은 없어요. PC는 끌어서 시야를 돌려요.

## 1. 이름 거르기

**추천(Codex 검토 반영): 아무 방이나(공개 방)에서는 자동 이름만, 코드 방(친구끼리)에서는 직접 쓴 이름.** 공개 방의 이름은 각자의 익명 UID에서 정해지는 자동 이름("포근한 눈송이 37")이에요. 보는 사람의 브라우저가 UID로 이름을 직접 만들어서, 누가 브라우저 코드를 고쳐도 남의 화면에 다른 이름을 띄울 수 없어요(서버가 필요 없어요). 코드 방에서는 직접 쓴 이름을 보여 주고, 저장 전에 금지어(한글·영어, 초성·띄어쓰기·특수문자 섞은 변형)와 연락처 모양(전화번호, `@아이디`, 주소)을 거르고, K4 규칙에서는 길이와 글자 종류를 확인해요.

- 다른 방법 A: **직접 입력 없이 자동 이름만** (형용사 + 눈 관련 명사). 나쁜 이름이 아예 안 생겨서 가장 안전하지만, 내 이름을 정하는 재미가 없어요.
- 다른 방법 B: 자유 입력 + 신고만. 만들기 쉽지만 나쁜 이름이 먼저 보이고 나중에 지워져요.
- 위험: 금지어 목록은 브라우저 코드에 있어서 누구나 볼 수 있고, 마음먹으면 피해 갈 수 있어요(Codex 지적: 브라우저 검사만으로는 공개 방 이름을 지킬 수 없어요). 그래서 공개 방은 자동 이름만 쓰고, 금지어는 친구끼리인 코드 방의 장난을 줄이는 용도예요.
- 시험할 것: 연락처 모양이 걸리는지, 정상 이름이 잘못 걸렸을 때 이유와 함께 다시 쓰게 하는지.

## 2. 차단

**추천: 내 화면에서만 숨기는 차단.** 다른 눈사람을 누르면 "이 사람 숨기기"가 나오고, 누르면 그 사람의 눈사람·이름·이모티콘이 내 화면에서 사라져요. 숨긴 목록은 이 브라우저에만 저장해요(K4의 UID 기준). 서버가 필요 없어요.

- 다른 방법: 차단당한 사람에게도 내가 안 보이게(양쪽 숨기기). 규칙에 차단 목록을 둬야 해서 K4가 커져요.
- 위험: 상대가 새로 들어오면(익명 UID가 바뀌면) 다시 보여요. 방을 바꾸거나 혼자로 가는 길도 같이 안내해요.

## 3. 신고

**추천: 지금은 만들지 않고, 공개(K5) 전에 다시 정하기.** 신고는 누군가 읽고 처리해야 의미가 있는데, 지금은 처리할 사람이 도윤뿐이에요. 대신 숨기기와 "혼자 있기"로 바로 피할 수 있게 해요. 그 전까지는 **초대한 사람끼리 시험하는 범위**로만 열어요.

공개 전에 정할 것(Codex 검토): 신고를 받는 곳, 누가 언제 확인하는지, 무엇을 저장하는지(UID, 방, 시각, 이유)와 언제 지우는지, 새 익명 계정으로 다시 오거나 여러 방에서 반복하는 사람을 운영자가 알아볼 신호.

- 다른 방법: `reports/`에 쓰기만 되는 칸을 두고 도윤이 가끔 Firebase 콘솔에서 확인. 만들기는 쉽지만, 아무도 안 읽는 신고 버튼은 믿음을 깎아요.
- 위험: 공개 후 사람이 많아지면 신고 없이는 반복하는 사람을 막기 어려워요.

## 4. 글자 채팅

**추천: 계속 없음 (이모티콘만).** 힐링 공간에서 가장 흔한 문제(욕, 개인 정보 묻기, 외부 메신저로 끌어내기)를 처음부터 막아요. 이모티콘 종류를 늘리는 건 안전해요.

- 다른 방법: 정해 둔 문장만 보내기("안녕", "고마워", "같이 걸을래?"). 이모티콘보다 말하는 느낌이 나고 여전히 안전해요. 나중에 원하면 이걸 먼저 추천해요.

## 5. 음성 대화 (수다 마당)

**추천: 공개 방에서는 하지 않고, 코드로 만든 방(친구끼리)에서만, 공개 뒤에 따로 만들기.** 방에 들어가는 것과 음성을 켜는 것은 따로 골라요(Codex 검토): K4가 확인한 방 멤버에게만 연결 정보를 주고, 마이크는 내가 직접 켜야 연결돼요. 숨긴 사람의 소리는 따로 끊고, 음소거·방 나가기·혼자 있기로 바꿀 때 마이크와 연결이 정리되는지 시험해요.

- 방법: 브라우저끼리 직접 잇는 WebRTC. 연결 정보 주고받기(시그널링)는 Firebase로 할 수 있어요. 학교·회사 인터넷처럼 직접 연결이 막힌 곳은 중계 서버(TURN)가 필요하고, 이건 돈이 들어요.
- 다른 방법 A: 공개 방에서도 음성 (말하기 버튼을 누를 때만, 기본은 꺼짐, 사람마다 음소거). 가장 재미있지만 위험이 가장 커요.
- 다른 방법 B: 음성 없이 이모티콘·정해 둔 문장만.
- 위험: 모르는 사람의 목소리(나이를 알 수 없음), 녹음, 괴롭힘. 중계 서버 비용. 브라우저 마이크 권한 안내. 공개 방 음성은 신고·차단이 먼저 있어야 해요.

## 6. 폰 조작

**추천: 왼쪽 아래 가상 조이스틱 + 오른쪽 화면을 끌어서 시야, 바닥 톡 걷기는 남기기.** 걷기 게임에 익숙한 사람은 조이스틱을, 처음인 사람은 톡 걷기를 써요.

- 다른 방법: 톡 걷기만 (지금). 단순하지만 오래 걷기엔 손가락이 바빠요.
- 위험: 조이스틱이 이모티콘 막대·버튼과 겹치지 않게 화면 배치를 다시 봐야 해요(390 × 844 기준). 시험 `phone`도 늘려요.
- 손가락 규칙(Codex 검토): 조이스틱이나 버튼에서 시작한 손가락은 걷기 목표를 만들지 않아요. 끌기로 바뀐 손가락도 뗄 때 걷기 목표를 만들지 않아요. 두 손가락 동시, 손가락이 버튼 밖으로 나감, 입력 취소(`touchcancel`), 화면 회전에서는 걷기가 멈춰요. 이 경우들을 시험에 넣어요.

## 7. 열려 있는 질문 두 개 (`AGENTS.md` 7번)

1. **끌지 않고 마우스만 움직여도 시야 돌리기 (FPS 방식)**: 추천은 **지금처럼 끌기**예요. FPS 방식은 마우스 포인터가 사라지고 Esc로 빠져나와야 해서, 버튼을 누르거나 쉬는 화면에는 덜 편해요. 원하면 "시야 고정 모드"를 켜고 끄는 키로 둘 수 있어요.
2. **지도 눌러 걷기를 뺄지**: 추천은 **남기기**예요. 폰에서는 먼 구역으로 가는 가장 쉬운 길이고, PC에서도 길 찾기가 서툰 사람에게 도움이 돼요.

## 8. 광고 (나중에)

이미 정한 것: 애드센스는 보호자 명의. 추천은 **처음 화면(꾸미기 창) 아래에만, 세계 안과 앉은 화면에는 절대 넣지 않기**예요. 쉬러 온 화면에 광고가 끼면 이 사이트의 목적이 무너져요. 공개(K5)와 이용자 수를 보고 다시 정해요.

## 도윤이 고를 것

1. 이름: 공개 방은 자동 이름 + 코드 방은 직접 쓴 이름(추천) / 어디서나 자동 이름만 / 어디서나 직접 쓴 이름
2. 차단: 내 화면에서만 숨기기(추천) / 양쪽 숨기기
3. 신고: 공개 전에 다시 정하기(추천) / 지금 쓰기만 되는 칸 만들기
4. 글자 채팅: 계속 없음(추천) / 정해 둔 문장만 보내기
5. 음성: 코드 방에서만, 공개 뒤에(추천) / 공개 방도 / 음성 없음
6. 폰: 조이스틱 + 톡 걷기(추천) / 톡 걷기만
7. 시야: 지금처럼 끌기(추천) / FPS 방식 / 키로 켜고 끄기
8. 지도 눌러 걷기: 남기기(추천) / 빼기

## 나누기 (고르고 나서)

- Claude: 화면(숨기기 메뉴, 이름 안내, 조이스틱, 실패 안내 글씨), UID로 자동 이름 만들기, 금지어·연락처 모양 확인 함수, 손가락 규칙, 시험.
- Codex: K4 규칙에 이름 길이·글자 종류 확인, 음성의 시그널링과 중계 서버 조사(5번을 고르면), 실제 폰에서 조작 확인.
